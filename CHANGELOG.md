# Changelog

## 0.1.0 — Pre-release ready

This local package version defines the initial public API:

- Double-sided surface and sequence types, including finite sequences.
- Transition outcomes with logical selection updates only after a settled
  front surface.
- Idle-only atomic recentering and logical-radius cache planning.
- Per-surface revision decisions, motion configuration, and accessibility
  content models.
- An iOS 17 page-curl presenter with two example projects: BookPreviewDemo and
  PhotoAlbumDemo.
- macOS 14 model APIs without a visual page-curl presenter.

The repository includes DocC articles and maintained guides in English,
Japanese, Korean, Simplified Chinese, and Traditional Chinese.
