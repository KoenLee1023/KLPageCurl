# 마이그레이션

기존 논리 페이지를 `ID`에 연결하고 `KLPageCurlSequence`로 앞뒷면을 설명합니다. 뒷면에 정착해도 앱의 선택 값은 갱신하지 말고, 다음 앞면이 정착할 때까지 기다립니다. 표면별 콘텐츠 버전은 `revision` 클로저로 옮겨 앞면 편집이 뒷면을 다시 만들지 않게 합니다.

지연된 컨트롤러 재설정은 한 번의 프로그래밍 방식 선택 갱신으로 바꿉니다. 페이저가 대기 상태이면 `initialSurface(for:)`가 초기 표면을 선택합니다. 일반적으로 앞면이지만 시퀀스 정책에 따라 달라질 수 있으며, 상태 머신은 그 표면과 선택 값을 함께 갱신합니다. 전환 중인 재배치 요청은 무시되어 현재 전환을 유지합니다.

캐시 반경은 0부터 8까지 설정할 수 있습니다. 기본값 1은 중앙 항목과 양쪽의 사용 가능한 인접 항목을 하나씩, 앞뒷면 모두 유지합니다. 새 범위 밖의 컨트롤러는 제거하고 리비전 새로 고침은 전환이 끝날 때까지 기다립니다.

내비게이션 정책은 호스트에 둡니다. 내비게이션 컨트롤러의 대화형 뒤로 가기 인식기를 페이지 컨트롤러에 전달합니다. 페이지 제스처는 해당 인식기의 실패를 기다리지만 KLPageCurl은 가장자리 너비를 정하지 않습니다.

호스트의 동작 줄이기 설정을 `reducedMotion`으로 바꾸면 선택한 항목의 초기 표면을 정적으로 표시합니다. VoiceOver와 스위치 제어를 위해 현지화된 레이블, 값, 알림, 이전과 다음 동작 이름을 제공합니다. 유한 시퀀스는 `BookPreviewDemo`, 리비전 기반 콘텐츠는 `PhotoAlbumDemo`를 참고하십시오. 컬 UI는 iOS 17 이상에서 제공되고, macOS 14에서는 모델 API만 사용할 수 있습니다.
