# 손쉬운 사용

사용자에게 보이는 손쉬운 사용 문구는 호스트가 `KLPageCurlAccessibility`로 제공합니다. 앞면과 뒷면에는 서로 다른 값과 정착 알림을 지정하고, 이전과 다음 동작의 이름을 현지화합니다.

iOS 17의 페이저는 증가와 감소 조절 동작, 사용자화한 이전과 다음 동작을 제공합니다. VoiceOver와 스위치 제어는 페이지 제스처와 같은 앞뒷면 순서를 이동합니다. 선택 값은 앞면에 정착했을 때만 바뀌고 `onSettled`는 양쪽 표면을 모두 알립니다. 페이지 안의 버튼, 입력 필드와 다른 손쉬운 사용 하위 요소도 숨기지 않습니다.

움직임을 줄여야 하면 `reducedMotion`을 전달합니다. 정적 표현은 선택한 항목의 `initialSurface(for:)`가 정한 초기 표면을 바로 보여 주며, 선택이 바뀌어도 뒷면 애니메이션을 거치지 않습니다. 캐시 반경과 표면별 리비전의 의미는 같으며 새로 고침은 전환이 끝날 때까지 기다립니다.

대화형 뒤로 가기는 내비게이션 호스트가 소유합니다. 페이지 제스처는 전달받은 인식기를 우선하며 KLPageCurl은 가장자리 임계값을 관리하지 않습니다. `BookPreviewDemo`는 이름이 있는 페이지 동작을 보여 주고, `PhotoAlbumDemo`는 컬과 정적 표현에서 편집 가능한 손쉬운 사용 하위 요소를 보여 줍니다. macOS 14에서는 관련 모델을 사용할 수 있지만 컬 UI는 없습니다.
