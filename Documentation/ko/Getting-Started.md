# 시작하기

논리 항목마다 안정적이고 `Hashable`, `Sendable`을 준수하는 ID를 준비합니다. 고정
목록에는 `KLFinitePageCurlSequence`를 사용할 수 있습니다. 다른 모델에서 인접
항목을 구한다면 `KLPageCurlSequence`를 구현합니다. 순서는 `front(id)`,
`back(id)`, `front(nextID)`로 유지하고 유한한 경계에서는 `nil`을 반환합니다.

`KLPageCurlPager`에 선택 바인딩, 시퀀스, 표면별 `revision`, 앞뒷면 뷰 빌더,
구성, 손쉬운 사용 문구를 전달합니다. 선택 값은 정착한 앞면만 나타내고
`onSettled`는 앞뒷면을 모두 받습니다. 프로그래밍 방식으로 선택을 변경하면 대기 중인
페이저는 `initialSurface(for:)`가 고른 초기 표면으로 원자적으로 이동합니다. 보통은
앞면이지만 시퀀스 정책에 따릅니다. 전환 중이었다면 정착한 뒤 필요한 선택
값을 다시 전달합니다.

캐시 반경은 인접 ID의 수입니다. 범위 안에서는 앞뒷면을 모두 유지하고 아직 캐시하지
않은 앞면만 미리 불러옵니다. 각 표면에 안정적인 리비전을 제공해야 합니다. 변경된
표면은 대기 상태에서 다시 불러오며 전환 중에는 새로 고침을 미룹니다.

기본 유한 시퀀스는 `BookPreviewDemo`, 표면별 리비전은 `PhotoAlbumDemo`에서 확인할
수 있습니다. 보이는 컬 표현은 iOS 17 이상, 뷰가 없는 모델 계층은 macOS 14
이상에서 지원합니다.
