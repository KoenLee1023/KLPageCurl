# 輔助使用

宿主透過`KLPageCurlAccessibility`提供所有面向使用者的輔助使用文字。正面與
背面應使用不同的值，分別提供停駐播報，並為上一頁、下一頁操作提供本地化名稱。

在iOS 17上，分頁器提供可調整的增減操作，以及自訂上一頁、下一頁操作。
VoiceOver與切換控制會沿著和頁面手勢相同的正反面序列移動。選取項目仍只在正面
停駐後更新，`onSettled`會回報兩種表面。頁面內的按鈕、輸入欄位等輔助使用子
元素不會被隱藏。

需要減少動態效果時傳入`reducedMotion`。靜態模式直接顯示
`initialSurface(for:)`選擇的初始表面（通常是正面，但由序列策略定義），選取
變更時直接接受該表面，不經過中間表面動畫。快取半徑與依表面修訂的語意不變，
修訂更新仍會等待轉場閒置。

互動式返回歸導覽宿主所有。頁面手勢會讓宿主傳入的辨識器優先，KLPageCurl不
管理邊緣門檻。`BookPreviewDemo`示範具名頁面操作，`PhotoAlbumDemo`示範翻頁與
靜態模式中的可編輯輔助使用子元素。macOS 14可使用輔助使用與動態效果模型，但
沒有翻頁UI。
