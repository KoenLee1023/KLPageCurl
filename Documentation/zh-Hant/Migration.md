# 遷移

先將現有邏輯頁面對應為`ID`，再用`KLPageCurlSequence`描述正反兩面。背面停駐
時不要更新應用程式的選取項目，應等到下一個正面停駐。將各表面的內容版本放入
`revision`閉包，修改正面時便不會重建背面。

以一次程式化選取更新取代延遲重設控制器。分頁器閒置時，
`initialSurface(for:)`會選擇初始表面（通常是正面，但由序列策略定義），狀態機
會接受該表面，同時更新可見控制器與快取計畫。轉場進行中時會忽略重新置中，並
維持目前轉場不變。

快取半徑可設為0到8。預設值1會保留中心項目及兩側各一個可用相鄰項目的正反
兩面。新範圍之外的控制器會被移除，修訂更新會等到轉場閒置。

導覽規則應保留在宿主。將導覽控制器的互動式返回辨識器傳給頁面控制器。頁面
手勢會等待它失敗，但KLPageCurl不會決定邊緣寬度。

將宿主的「減少動態效果」設定轉為`reducedMotion`，以靜態方式顯示
`initialSurface(for:)`選擇的初始表面（通常是正面，但由序列策略定義）。
為VoiceOver與切換控制提供本地化標籤、值、播報，以及上一頁、下一頁名稱。
有限序列可參考`BookPreviewDemo`，修訂驅動內容可參考`PhotoAlbumDemo`。翻頁UI
始於iOS 17；macOS 14僅提供模型API。
