# アクセシビリティ

ユーザー向けのアクセシビリティ文言は、ホストが`KLPageCurlAccessibility`で
指定します。表と裏で異なる値、個別の遷移完了通知、ローカライズした前後
アクション名を用意します。

iOS 17のページャーは増減の調整アクションと、カスタムの前後アクションを提供
します。VoiceOverとスイッチコントロールはページジェスチャーと同じ表裏順序を
移動できます。選択値は表面への遷移完了時だけ変わり、`onSettled`は表裏の両方
を通知します。ページ内のボタンや入力欄なども隠しません。

動きを抑える必要がある場合は`reducedMotion`を指定します。静止表示は
`initialSurface(for:)`が選ぶ初期表面（通常は表面ですが、シーケンスの方針で
決まります）を直接示し、選択変更時にも中間の表面をアニメーションしません。
キャッシュ半径と表面別リビジョンの意味は同じで、更新は遷移の完了を待ちます。

インタラクティブポップはナビゲーション側が所有します。ページジェスチャーは
渡された認識器を優先し、KLPageCurlはエッジしきい値を管理しません。
`BookPreviewDemo`は名前付きアクションを、`PhotoAlbumDemo`はカール表示と静止
表示の編集可能なアクセシビリティ要素を示します。macOS 14では関連モデルを
利用できますが、カールUIはありません。
