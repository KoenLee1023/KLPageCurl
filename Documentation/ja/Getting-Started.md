# はじめに

論理項目ごとに、安定していて`Hashable`と`Sendable`に準拠するIDを用意します。
固定リストには`KLFinitePageCurlSequence`を使えます。別のモデルから隣接項目を
求める場合は`KLPageCurlSequence`を実装します。順序は`front(id)`、`back(id)`、
`front(nextID)`とし、有限の端では`nil`を返します。

`KLPageCurlPager`には選択バインディング、シーケンス、表面別の`revision`、表裏
のビュー生成処理、設定、アクセシビリティ文言を渡します。選択値は遷移済みの
表面だけを表し、`onSettled`は表裏のどちらでも受け取ります。プログラムからの
選択変更では、`initialSurface(for:)`が初期表面を選びます。通常は表面ですが、
シーケンスの方針で決まり、待機中の状態機械がその表面を原子的に受け入れます。
遷移中だった場合は、完了後に必要な選択値をもう一度送ります。

キャッシュ半径は隣接IDの数です。範囲内では表裏を保持し、未キャッシュの表面
だけを先読みします。各表面に安定したリビジョンを指定してください。変更された
表面は待機時に再読み込みされ、遷移中は更新を保留します。

基本的な有限シーケンスは`BookPreviewDemo`、表面別リビジョンは
`PhotoAlbumDemo`で確認できます。表示用のカールはiOS 17以降、ビューを持たない
モデル層はmacOS 14以降に対応します。
