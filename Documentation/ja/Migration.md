# 移行

既存の論理ページを`ID`に対応させ、`KLPageCurlSequence`で表裏を記述します。
裏面への遷移完了時にはアプリの選択値を更新せず、次の表面まで待ちます。表面
ごとの内容バージョンを`revision`クロージャーに移すと、表面の編集で裏面を作り
直さずに済みます。

遅延付きのコントローラー再設定は、1回のプログラム選択更新に置き換えます。
待機中は`initialSurface(for:)`が初期表面を選びます。通常は表面ですが、
シーケンスの方針で決まり、状態機械がその表面を受け入れると同時に、表示中の
コントローラーとキャッシュ計画も更新されます。遷移中の再配置は無視され、現在の
遷移を維持します。

キャッシュ半径は0から8です。既定値の1では、中央と両側の利用可能な隣接項目
を1件ずつ、表裏とも保持します。新しい範囲外のコントローラーは破棄され、
リビジョン更新は遷移の完了を待ちます。

ナビゲーション方針はホストに残します。ナビゲーションコントローラーの
インタラクティブポップ認識器をページコントローラーへ渡してください。ページ
ジェスチャーはその失敗を待ちますが、KLPageCurlはエッジ幅を決めません。

ホストの「視差効果を減らす」設定を`reducedMotion`へ変換し、
`initialSurface(for:)`が選ぶ初期表面（通常は表面ですが、シーケンスの方針で
決まります）を静止表示します。VoiceOverとスイッチコントロール向けに、ローカライズした
ラベル、値、通知、前後アクション名を渡します。有限シーケンスは
`BookPreviewDemo`、リビジョン駆動の内容は`PhotoAlbumDemo`を参照してください。
カールUIはiOS 17以降、macOS 14ではモデルAPIだけを利用できます。
