# 辅助功能

宿主通过`KLPageCurlAccessibility`提供所有面向用户的辅助功能文本。正面和背面
应使用不同的值，分别提供停靠播报，并为上一页、下一页操作提供本地化名称。

在iOS 17上，分页器提供可调节的增减操作以及自定义上一页、下一页操作。
VoiceOver和切换控制会沿着与页面手势相同的正反面序列移动。选择仍只在正面停靠
后更新，`onSettled`会报告两种表面。页面中的按钮、输入框等辅助功能子元素不会
被隐藏。

需要减弱动态效果时传入`reducedMotion`。静态模式直接显示
`initialSurface(for:)`选择的初始表面（通常是正面，但由序列策略定义），选择
变化时直接接受该表面，不经过中间表面动画。缓存半径和按表面修订的语义不变，
修订刷新仍会等待转场空闲。

交互式返回归导航宿主所有。页面手势会让宿主传入的识别器优先，KLPageCurl不
管理边缘阈值。`BookPreviewDemo`演示具名页面操作，`PhotoAlbumDemo`演示翻页和
静态模式中的可编辑辅助功能子元素。macOS 14可使用辅助功能和动态效果模型，但
没有翻页UI。
