# 迁移

先把现有逻辑页面映射为`ID`，再用`KLPageCurlSequence`描述正反两面。背面停靠
时不要更新应用选择，应等到下一个正面停靠。把各表面的内容版本放进`revision`
闭包，这样修改正面时不会重建背面。

用一次程序化选择更新替代延迟重置控制器。分页器空闲时，
`initialSurface(for:)`会选择初始表面（通常是正面，但由序列策略定义），状态机
会接受该表面，同时更新可见控制器和缓存计划。转场进行中时会忽略重新居中，并
保持当前转场不变。

缓存半径可设为0到8。默认值1会保留中心项目及两侧各一个可用邻居的正反两面。
新窗口之外的控制器会被移除，修订刷新会等到转场空闲。

导航策略应留在宿主。把导航控制器的交互式返回识别器传给页面控制器。页面手势
会等待它失败，但KLPageCurl不会决定边缘宽度。

把宿主的“减弱动态效果”设置转换为`reducedMotion`，以静态方式显示
`initialSurface(for:)`选择的初始表面（通常是正面，但由序列策略定义）。
为VoiceOver和切换控制提供本地化标签、值、播报以及上一页、下一页名称。有限
序列可参考`BookPreviewDemo`，修订驱动内容可参考`PhotoAlbumDemo`。翻页UI始于
iOS 17；macOS 14仅提供模型API。
